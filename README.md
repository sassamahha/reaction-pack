# reaction-pack

Free reaction emoji & sticker packs by **sassamahha** — odd costume characters for your team chat.
Also on LINE Stickers. More: https://sassamahha.me

sassamahha の無料リアクション絵文字・スタンプ集です。Slack / Microsoft Teams / Discord でそのまま使えます。
LINEスタンプ版もあります → https://sassamahha.me

## How to use / 使い方

1. Download a ZIP below. / 下のZIPをダウンロード
2. Add the PNGs as custom emoji. File names become emoji names (`lgtm_rooster`).
   - **Slack**: workspace name → Customize workspace → Add Custom Emoji
   - **Microsoft Teams**: emoji picker → Your org's emoji → Add (admin must allow custom emoji; desktop/web)
   - **Discord**: Server Settings → Emoji → Upload Emoji (select all at once)

Each emoji: 128×128 transparent PNG, under 128 KB.
