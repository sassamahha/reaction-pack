# reaction-pack

Free reaction emoji & sticker packs by **sassamahha** — odd costume characters for your team chat.
Works in Slack, Microsoft Teams and Discord. Also on LINE Stickers → https://sassamahha.me

sassamahha の無料リアクション絵文字集です。Teams / Slack / Discord でそのまま使えます。
LINEスタンプ版もあります → https://sassamahha.me

## How to use / 使い方

1. Download a ZIP below. / 下のZIPをダウンロード
2. Add the PNGs as custom emoji. File names become emoji names (`lgtm_rooster`, `ryokai_rooster`).
   - **Microsoft Teams**: emoji picker → Your org's emoji → Add (admin must allow custom emoji; desktop/web) / 絵文字ピッカー → 組織の絵文字 → 追加
   - **Slack**: workspace name → Customize workspace → Add Custom Emoji / ワークスペースをカスタマイズ → カスタム絵文字を追加
   - **Discord**: Server Settings → Emoji → Upload Emoji / サーバー設定 → 絵文字 → アップロード

Each emoji: 128×128 transparent PNG, under 128 KB.
